# Hallucination Audit of AI Chatbots

A beginner-friendly Python project that checks chatbot answers against a small set of trusted reference facts and identifies statements that may be unsupported.

**Prepared by:** M. Parinitha  
**Department:** Artificial Intelligence and Data Science  
**College:** Dhanalakshmi College of Engineering

## 1. Project overview

AI chatbots can sometimes produce information that sounds correct but is false or unsupported. This is commonly called an **AI hallucination**.

This project provides a simple, explainable baseline audit:
1. Read chatbot answers from a CSV file.
2. Compare each answer with the trusted reference facts supplied for that question.
3. Split the answer into sentences.
4. Calculate text similarity between each sentence and the reference facts.
5. Mark sentences as `SUPPORTED` or `REVIEW NEEDED`.
6. Calculate a simple audit summary and save the results as a CSV report.

> Important: This is an educational prototype, not a reliable scientific detector. Text similarity cannot prove whether a statement is true. A sentence marked `REVIEW NEEDED` should be checked by a human. A sentence marked `SUPPORTED` may still contain an error.

## 3. Requirements

- Python 3.9 or later
- No external Python packages are required

## 4. Run the project

Open a terminal in the project folder and run:

```bash
python src/audit.py
```

The audit report will be created at:

```text
reports/audit_report.csv
```

On some Windows systems, use `py src/audit.py`.

## 5. Input format

Edit `data/sample_answers.csv` using these columns:

| Column | Meaning |
|---|---|
| `question` | Question asked to the chatbot |
| `chatbot_answer` | Answer generated by the chatbot |
| `reference_facts` | Trusted facts to compare against, separated by `;` |

Use sources you trust when preparing reference facts. Keep each row's reference facts relevant to its question.

## 6. Understanding the output

The report contains:
- `sentence`: one sentence from the chatbot answer
- `similarity`: approximate text similarity score from 0 to 1
- `status`: `SUPPORTED` or `REVIEW NEEDED`

The threshold is configurable in `src/audit.py` using `SIMILARITY_THRESHOLD`. The default is `0.25` and is only a demonstration setting; it is not a validated accuracy threshold.

## 7. Example

Question: What is the capital of France?  
Chatbot answer: The capital of France is Paris.  
Reference fact: France's capital city is Paris.

The sentence should receive a similarity score and an audit status. Try changing the chatbot answer to an incorrect statement and run the program again.

## 8. Limitations and future improvements

- Similar wording can be mistaken for factual support.
- Correct statements written in different words may be flagged.
- The tool does not search the internet or independently verify sources.
- The quality of the result depends on the reference facts.
- Future versions could use human evaluation, reliable retrieval sources, natural-language inference models, and larger test datasets.
